# Aura Farming - Minecraft Mod

> ⚠️ **Project Status:** In active development (WIP). Expect bugs and frequent updates!

## 📥 Installation

To install this mod, you need the **Fabric modloader** and the following dependencies:

- **Minecraft:** `26.3`
- **Fabric Loader:** `0.19.5` (or higher)
- **Fabric API:** `>= 0.162.0+26.3`
- **Fantasy:** `>= 0.8.4+26.3`

*(Don't forget to drop the mod `.jar` file into your `mods` folder!)*

---

## ✨ Features

- **Mechanics Overhaul:** Re-imagines core features like enchanting tables and item durability.
- **Aura Battles (vs Mobs):** Engage in turn-based "Aura Battles" against non-player mobs, inspired by Pokémon mechanics!
- **Multiplayer Stakes:** Challenge your friends (or enemies) on servers. Bet your rare items and aura points—the first to fall loses everything they wagered.
